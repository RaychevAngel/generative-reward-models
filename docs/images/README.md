# README figure

`capacity-allocation.png` is a raster preview of the numerically reconstructed
`build/reproduction/arxiv/figures/restored/capacity-allocation.pdf`. The PDF and
its source-summary table are generated by `make figures` from retained CSVs.

For an updated README preview, Poppler can render the regenerated vector:

```sh
pdftoppm -singlefile -png -r 155 \
  build/reproduction/arxiv/figures/restored/capacity-allocation.pdf \
  docs/images/capacity-allocation
```

Poppler is optional and is not required for the numerical/PDF reproduction
commands. This preview introduces no new data or fitted points.
